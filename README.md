# news-image-20261124

## Run it

```sh
python3 main.py
```

This copies the bundled `entry.png` (drawn by `draw.py` with Pillow) to `/output/entry.png`. Set `MAKEFUN_OUTPUT_DIR` to write somewhere else for a local check, e.g. `MAKEFUN_OUTPUT_DIR=out python3 main.py`.

## How the image was made

`draw.py` draws a 1024×1024 newspaper front page in English: masthead with the date, a hero story on Nvidia's CEO reversal and record $952bn share surge, six further stories (Hormuz tankers, the Riyadh tower strike, the Gaza strike, the EU's 22nd Russia sanctions package, the reported Russian space weapon, and the Rohingya genocide ruling), an "Also today" line (Nepal earthquake, 2031 Women's World Cup hosts), and a bottom markets strip. No network is used; the output is deterministic.
